# RUFUS — Caption Bank

Instagram / TikTok captions for every published still and clip. Two types:

- **Type A — in-scene irony (70% of posts).** Deadpan, matches what is
  actually happening in the frame. 1 word minimum, 2 sentences maximum.
  The joke is always that Rufus's situation is being described as if it
  were normal.
- **Type B — unrelated raccoon biology (30% of posts).** A true, documented
  fact about raccoons in general, delivered deadpan, with absolutely no
  connection to what is happening in the post. The mismatch IS the joke.
  Exempt from the 2-sentence cap.

**Usage rules:** for every 10 posts, 7 get a Type A and 3 get a Type B.
Never both on one post. Type B lands hardest on the most chaotic images —
maximum mismatch. All facts below are documented; do not invent new ones
without checking. Lowercase is the house voice; punctuation minimal.

**Carousel pairings:** community + rogue versions of the same setting run
as two-slide carousels (ATM day → ATM night is the canonical pair). Caption
the carousel from the FIRST slide's set — the second slide is the punchline
and needs no help.
